# Prospail (Postrichment) - Autonomous AI GTM & Prospect Enrichment

An agentic AI-powered outbound sales & prospecting platform.

## Live Deployments
- **Frontend App**: [https://prospail.vercel.app](https://prospail.vercel.app)
- **Backend API**: [https://prospail.onrender.com](https://prospail.onrender.com)

## Tech Stack
- **Frontend**: Next.js 16 (App Router, Turbopack, React 19), Redux Toolkit, TailwindCSS, Auth.js v5
- **Backend**: Node.js, Express, Drizzle ORM, PostgreSQL, Google Auth Library
- **AI/LLM**: Google Gemini 2.0 / 1.5 Flash, Web Scraping & Semantic Ingestion
